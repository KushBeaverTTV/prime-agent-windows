- Branch summaries now run through the `auxiliaryModel` setting, not just refinement and compaction passes. Branch summarization fires at a tree-navigation context boundary and the summarizer uses its own prompt prefix, so running it on the session model evicted the provider's prompt-cache entry for the session and paid full input price at context peak. The summary falls back to the session model when the setting is unset, unusable, or its context window cannot hold the summary request the session model would issue.
- Branch summaries never request the session's thinking level. Summarizing is transcription rather than reasoning, and the summary call stays cheap without a reasoning option.
